# Python Programs Repository

## Project Description

This repository contains simple Python programs for practicing basic programming concepts.

The repository includes:

- **factorial.py** – Calculates the factorial of a number.
- **fibonacci.py** – Generates Fibonacci numbers.
- **struct program.py** – Stores student information in a Python dictionary and displays the student's name, roll number, and marks.
- **sphere_area.py** – Calculates the surface area of a sphere using its radius.
- **arithmetic_operations.py** – Performs addition, subtraction, multiplication, and division on two numbers and handles division by zero.
- **greater_number.py** – Compares two numbers and displays the greater number or states that both numbers are equal.

## Programs

### 1. factorial.py

This program calculates the factorial of a number.

### 2. fibonacci.py

This program generates Fibonacci numbers.

### 3. struct program.py

This program stores student information in a Python dictionary and displays the student's name, roll number, and marks.

### 4. sphere_area.py

This program calculates the surface area of a sphere using the radius provided by the user.

### 5. arithmetic_operations.py

This program takes two numbers and performs addition, subtraction, multiplication, and division. It also handles division by zero.

### 6. greater_number.py

This program compares two numbers and displays the greater number or states that both numbers are equal.

## How to Run

Make sure Python is installed on your computer.

Run the programs using:

```bash
python factorial.py
python fibonacci.py
python "struct program.py"
python sphere_area.py
python arithmetic_operations.py
python greater_number.py
```
## Requirements

- Python 3
- No external dependencies are required.
