# Python Programs Repository

## Project Description

This repository contains simple Python programs for practicing basic programming concepts.

The repository currently includes:

- **factorial.py** – Calculates the factorial of a number.
- **fibonacci.py** – Generates Fibonacci numbers.
- **structprogram.py** – Stores student information in a Python dictionary and displays the student's name, roll number, and marks.

## Programs

### 1. factorial.py

This program calculates the factorial of a number.

### 2. fibonacci.py

This program generates Fibonacci numbers.

### 3. structprogram.py

This program stores student information in a Python dictionary and displays the student's name, roll number, and marks.

## How to Run

Make sure Python is installed on your computer.

Run a program using:

```bash
python factorial.py
