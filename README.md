# Python Programs Repository

## 1. Objective

The objective of this repository is to practice and demonstrate fundamental Python programming concepts through six simple programs.

The repository aims to:

- Understand basic Python syntax and programming logic.
- Practice variables, arithmetic operations, loops, and conditional statements.
- Learn how to accept user input and display output.
- Organize Python programs using GitHub and maintain meaningful commit messages.
- Create accurate project documentation and verify its claims against the actual source code.

## 2. Programs Included

This repository contains six Python programs: three classwork programs (CW) and three homework programs (HW).

### Classwork Programs (CW)

**1. factorial.py**  
Calculates the factorial of a number using a for loop.

**2. fibonacci.py**  
Generates Fibonacci numbers using a loop and variable updates.

**3. struct program.py**  
Stores student information in a Python dictionary and displays the student's name, roll number, and marks.

### Homework Programs (HW)

**4. sphere_area.py**  
Calculates the surface area of a sphere using a radius entered by the user.

**5. arithmetic_operations.py**  
Accepts two numbers and performs addition, subtraction, multiplication, and division. It also handles division by zero.

**6. greater_number.py**  
Compares two numbers and displays the greater number or states that both numbers are equal.

## 3. Installation and Setup Steps

**Step 1: Install Python**

Download and install Python 3 from the official website:

https://www.python.org/downloads/

**Step 2: Verify Python Installation**

Open Command Prompt or Terminal and run:

`python --version`

If Python is installed correctly and the command is available, the installed version will be displayed.

**Step 3: Download the Repository**

Open the GitHub repository:

https://github.com/vittikabairathi35-maker/python-basics-25BCON1791

Click **Code → Download ZIP** and extract the downloaded ZIP file.

**Step 4: Open the Project Folder**

Open Command Prompt or Terminal inside the extracted repository folder.

**Step 5: Run the Python Programs**

Execute the following commands individually:

    python factorial.py
    python fibonacci.py
    python "struct program.py"
    python sphere_area.py
    python arithmetic_operations.py
    python greater_number.py

For programs requiring user input, enter the requested values in the terminal.

## 4. Dependencies

The following requirements are needed to run the programs:

- **Programming Language:** Python 3
- **Operating System:** Windows, macOS, or Linux with Python installed
- **External Libraries:** None
- **Python Packages:** No additional packages need to be installed
- **Internet Connection:** Required to download Python and the repository, but not to run the programs locally

All six programs use Python's built-in functionality and do not require third-party libraries.
